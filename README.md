# Laravel Clean Starter

A clean, Blade-first Laravel boilerplate with:
- Action pattern
- DTOs
- Form Requests
- Performance-first queries
- Flexible ListQuery helper

## Included
- Clean folder structure
- Example Task CRUD (Blade)
- Pagination-first queries
- Safe defaults for production

## Installation
```bash
git clone https://github.com/yourname/laravel-clean-starter.git
cd laravel-clean-starter
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
